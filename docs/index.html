ARM LAB 실습 안내

    
① 6축 로봇팔: J1~J3은 위치, J4~J6은 손목 자세를 제어합니다. 툴 방향 슬라이더는 역기구학으로 TCP 위치를 유지합니다. 개별 관절 조작은 순기구학으로 TCP도 이동합니다.

    
로봇 교시 모드에서 바닥을 드래그해 팔을 움직입니다. 높이 슬라이더로 위아래를 조절합니다.

    
② 평행 그리퍼의 검은 접촉 패드 사이에 물체를 두고 아래를 향하도록 정렬하세요. 물체 중심 근처에서 그리퍼를 닫으면 잡습니다. 상자를 클릭하거나 상자에 맞추기를 누르면 위치와 높이가 자동 정렬됩니다. 파지 시 좌우 오차를 최대 70 mm까지 보정하는 교육용 보조 기능입니다. 기록 시작 후 시연하고 기록 종료 → 재생하세요.

    
③ 물체 위치를 바꾼 뒤 자동 운전을 실행하면 가상 위치 센서와 접촉 정보를 사용해 초록 영역으로 옮깁니다.

    
④ JSON으로 실습 데이터를 저장·복원합니다. 현재 브라우저에도 마지막 기록이 저장됩니다.

    
거리 센서는 TCP에서 아래로 레이캐스팅합니다. 카메라는 실제 3D 상부 렌더입니다. 물체 좌표는 시뮬레이터에서 제공하는 이상적인 위치 센서이며 영상 AI 검출이 아닙니다.
