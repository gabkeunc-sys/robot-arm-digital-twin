# ARM LAB · 로봇팔 디지털트윈

교육용 브라우저 로봇 시뮬레이터. Three.js 0.170.0 + cannon-es 0.20.0.

## 실행
`dist/`를 정적 웹 서버로 제공합니다. 빌드나 데이터베이스가 필요 없습니다.

- 바닥 드래그로 XZ 이동, 높이 슬라이더로 Y 이동, 3관절 역기구학
- 물체 배치, 그리퍼 근접 집기와 해제
- 10 Hz 교시 기록, 재생, localStorage 저장, JSON 가져오기/내보내기
- 가상 거리 센서, 관절 엔코더, 접촉 상태, 상부 카메라, 이상적인 물체 위치 센서
- 센서 기반 자동 집기/운반 상태기계
- 중력, 질량, 마찰 조절; 물체 강체 낙하/바닥 충돌
- WebGL2 및 Canvas 2D 호환 렌더링

## 교육 범위와 모델
웹 자체 시뮬레이터로 실제 ROS2/Gazebo 서버는 포함하지 않습니다. 토픽 모니터는 브라우저 내부 데이터입니다. 로봇은 기구학 제어이며 링크 자체의 강체 충돌·토크 동역학은 모델링하지 않습니다. 물체는 cannon-es 강체입니다. 집기는 근접 조건에서 기구학 부착으로 모델링합니다. 힘 표시는 mg 추정값입니다. 영상 AI가 아닌 이상적 위치 센서를 사용합니다. 교시 재생과 상태기계 자동 운전이며 신경망 모방학습은 아닙니다.

## 실습
1. 기록 시작 → 팔 이동/높이 조절/그리퍼 → 기록 종료 → 재생.
2. 물체 위치 무작위 변경 → 자동 운전 → 목표 영역 도달 확인.
3. 중력·질량 변경 후 추정 하중 변화 관찰.
4. 거리 센서 노이즈를 켜고 관측값 변화를 비교.

기록은 브라우저에 저장됩니다. JSON으로 내보내면 다른 PC에서 복원할 수 있습니다. 외부 서버로 실습 기록을 전송하지 않습니다.
